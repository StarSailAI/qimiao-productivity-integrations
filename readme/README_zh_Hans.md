# 奇妙生产力 Dify 插件

Personal Agent 的奇妙办公生产力工具箱。此版本支持查询实时能力与模板、免费准备上传材料、跟进已有任务及获取文件成果。

先用 `list_tools` 读取支持操作与当前 schema，再选对应操作并传入 JSON 参数。公开查询不需要 API Key；已有任务必须使用对应任务凭据。插件不提供账号连接、创建订单或付款操作。插件免费，远程制作服务可能收费，需要用户在第一方页面另行操作。

示例：为产品介绍查找简洁的 PPT 模板；了解采访视频添加中文字幕的工具；查询已有任务状态并取回文件。完整安装步骤、接口范围与隐私说明见英文 README 和 PRIVACY.md。
