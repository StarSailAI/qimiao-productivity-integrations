# 奇妙生产力 Dify 插件

Personal Agent 的奇妙办公生产力工具箱。根据实时能力目录，制作与处理 PPT、封面、网页、文档和音视频文件，从选择能力、准备材料到发起任务、跟进进度和取回文件，支持完整流程。具体能力与交付范围以实时目录为准。

## 使用方式

1. 安装插件；公开发现和匿名订单流程不要求 API Key，也不要求注册奇妙生产力账号。
2. 先调 `list_tools` 获取当前参数，再用 `get_service_overview`、`search_tools`、`get_tool` 了解能力；支持模板时请用户选择或明确认可模板。
3. 用户希望开始后用 `prepare_task` 准备材料，通过返回的私有网页上传附件，再用 `get_task_materials` 核对真实材料。
4. `quote_order` 固定本次需求、交付和价格；向用户展示准确金额与约定，用户同意后再调 `create_order`。
5. 默认把第一方订单确认页交给用户，无需登录奇妙生产力即可跳转支付宝逐单付款。服务端核实支付后执行，Agent 用 `get_order` / `wait_order` 跟进，最后 `get_run_result` 取回成果。0 元任务在用户要求开始后直接执行，不产生付款单。
6. 支持按原约定修改、回复制作中的问题、取消与恢复任务。重试保持原随机 `request_key`，付款不确定先查原单，不能重复购买；下载链接过期重取成果，不重新制作。

可选账号功能：用户自己在第一方网页登录并确认连接，Agent 可查授权状态与余额、撤销连接。只有用户明确确认本单任务、金额与约定后，才可调用 `pay_with_balance` 使用服务余额；不能编造确认，也不能将连接账号等同于消费授权。账号凭据不能作为公共应用中所有用户共享的默认值。

插件免费；制作服务可能按任务收费。插件不提供充值、订阅购买、转账或退款工具。退款及交付争议按官网规则联系支持邮箱。保管好任务凭据、私人找回凭证和成果链接；Dify 可能保存工作流输入输出，不要公开包含凭据的调试记录。

## 实现参考

参考了 Dify 市场已上架的支付宝支付、Ipaynow 现在支付、Lacuna Music 和 Sonilo 插件：分别借鉴用户在外部完成支付后查单、服务额度计费、异步任务与文件交付的方式。我们实现的是连接现有奇妙生产力服务的独立适配器，没有打包这些插件的源码。它们不一定由 Dify 开发，也不代表 Dify 已批准本插件的交易流程；两条付费路径均向审核人员完整披露。具体链接与区别见英文 README 的 Design references。

示例：制作一份产品介绍 PPT 并交付 PPTX 和 PDF；为文章制作指定风格的封面；给上传的采访添加字幕并交付视频与字幕文件。
